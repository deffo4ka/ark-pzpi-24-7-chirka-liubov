3 ОПИС ВИКОНАНОЇ РОБОТИ
Під час виконання практичного завдання було досліджено 3 методи рефакторингу за Мартіном Фаулером. Мовою реалізації обрано TypeScript.

Розглянуті методи:
1. Rename Method (Перейменування методу): Зміна неінформативної назви функції "calc" на "calculateTicketPrice" для кращого розкриття наміру та бізнес-логіки.
2. Replace Magic Number with Symbolic Constant (Заміна магічних чисел символьними константами): Заміна «магічних» числових літералів (18, 80, 100) на іменовані константи (AGE_OF_MAJORITY, DISCOUNTED_PRICE_UAH, STANDARD_PRICE_UAH) для централізованого управління конфігурацією.
3. Decompose Conditional (Декомпозиція умовного виразу): Виділення перевантаженої перевірки пільг в окремий метод-предикат "isEligibleForDiscount", що спростило основний потік виконання.

Для демонстрації було створено модуль розрахунку вартості квитків "TicketCalculator". Було проаналізовано проблеми оригінального коду та продемонстровано покращену версію, яка є самодокументованою, стійкою до розширення та готовою до модульного тестування (Unit-тестів).

4 ВИСНОВКИ
У результаті виконання роботи було практично застосовано 3 класичні методи рефакторингу. Отримано навички покращення читабельності, гнучкості та підтримки програмного коду. Доведено, що застосування методів Фаулера знижує когнітивне навантаження розробника, спрощує Code Review та робить код готовим до подальшого розвитку.

namespace Before {
  export class TicketCalculator {
    // 1. Rename Method: The name 'calc' is not descriptive
    // 2. Replace Magic Numbers: The numbers 18, 80, and 100 are used without explanation
    // 3. Break Down the Conditional: A complex conditional expression on a single line
    public calc(age: number, isStudent: boolean): number {
      if (age < 18 || isStudent) {
        return 80;
      }
      return 100;
    }
  }
}

В.2 Приклад програмного коду після рефакторингу
GitHub репозиторій: https://github.com/deffo4ka/ark-pzpi-24-7-chirka-liubov/blob/main/Pract2/code-examples-refactoring-methods.ts

namespace After {
  // Method 2: Replace the Magic Number with a Symbolic Constant
  const AGE_OF_MAJORITY = 18;
  const DISCOUNTED_PRICE_UAH = 80;
  const STANDARD_PRICE_UAH = 100;

  export class TicketCalculator {
    // Method 1: Rename Method (calc -> calculateTicketPrice)
    public calculateTicketPrice(age: number, isStudent: boolean): number {
      // Method 3: Decompose Conditional (extracting a complex condition into a predicate method)
      if (this.isEligibleForDiscount(age, isStudent)) {
        return DISCOUNTED_PRICE_UAH;
      }
      return STANDARD_PRICE_UAH;
    }

    // Helper method for checking eligibility for a discount
    private isEligibleForDiscount(age: number, isStudent: boolean): boolean {
      return age < AGE_OF_MAJORITY || isStudent;
    }
  }
}
