3 ОПИС ВИКОНАНОЇ РОБОТИ

Під час виконання практичного завдання було досліджено стандарти оформлення програмного коду (Code Conventions) для мови JavaScript/TypeScript.

Основні розглянуті правила:

1. Базові правила форматування: використання 2 пробілів для відступів, обмеження довжини рядка до 80-100 символів, використання пробілів навколо математичних та логічних операторів.

2. Конвенції іменування: використання camelCase для змінних і функцій, PascalCase для класів та типів, UPPER_SNAKE_CASE для констант. Використання змістовних назв без неіснуючих скорочень.

3. Документування коду: використання JSDoc для функцій з описом параметрів (@param) та типу повернення.

4. Типізація: використання const замість var, сувора рівність (===), уникнення небезпечного типу any у TypeScript, використання бібліотеки Zod для валідації даних під час виконання.

5. Автоматизація: застосування інструментів Prettier для автоматичного вирівнювання та ESLint для статичного аналізу коду.



Програмним інструментом для демонстрації було обрано середовище розробки Visual Studio Code. Для прикладу було створено схему валідації форми бронювання за допомогою бібліотеки Zod.



4 ВИСНОВКИ

У результаті виконання роботи було розглянуто ключові стандарти оформлення коду для мови JavaScript/TypeScript. Отримано навички з рефакторингу стилю коду, заміни неінформативних назв на описові, правильного форматування відступів та типізації даних. Дотримання цих правил дозволяє підвищити читабельність коду, спростити його підтримку та зменшити технічний борг проєкту.
